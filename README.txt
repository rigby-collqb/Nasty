Bem-vindo ao site vulnerável!

Este ambiente foi criado para você praticar suas habilidades com ferramentas como Nmap e Metasploit. Aqui estão as falhas que você pode explorar:

1. **Injeção de SQL**:
   - Página: login.php
   - Como testar: Enviar um payload de SQL através do formulário de login.

2. **Exposição de informações sensíveis**:
   - Página: config.php
   - Como testar: Acesse a página e veja as credenciais expostas.

3. **Upload de arquivo malicioso**:
   - Caminho: uploads/shell.php
   - Como testar: Faça o upload de um shell reverso PHP e execute.

4. **Exploração com Metasploit**:
   - Teste exploits para injeção de SQL e vulnerabilidades PHP.

Boa sorte e lembre-se de sempre testar em ambientes isolados!
